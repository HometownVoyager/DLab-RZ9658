# 接线演示与验收步骤（wiring-demo）

> 本文档给出**可照着做的验收流程**：从双击打开到完成一个真实数电实验的接线、观察、存取。
> 全部操作在浏览器内完成，无需安装任何东西、无需启动服务器。

---

## 0. 启动

**方式一（推荐）**：在文件管理器里双击

```
Teaching App/index.html
```

**方式二**：命令行

```
cd "Teaching App"
start index.html
```

启动后应当看到：顶部标题栏、居中的实验箱面板（等比缩放铺满窗口）、底部工具栏。
底部状态栏显示「就绪：点击任意插孔开始接线，再次点击另一插孔完成」。

> **为什么不用服务器也能跑？**
> 全部脚本以经典 `<script>` 加载（非 ES Module），面板 SVG 以字符串常量内嵌在
> `src/panel/panel.annotated.js` 中，运行时不读取任何本地文件，因此 `file://` 协议下不会被 CORS 拦截。

## 1. 界面速览

| 区域 | 位置 | 作用 |
| :-- | :-- | :-- |
| 顶部标题栏 | 最上方 | 产品名与平台型号 |
| 实验箱面板 | 中间主体 | 全部插孔、开关、数码管、DIP 插座 |
| 时序控制条 | 面板下方 | 运行/暂停、单步、复位时间、速度、时钟使能、虚拟时间读数 |
| 底部工具栏 | 最下方 | 导线颜色、撤销、重做、清空、导出、导入、显示导线、状态提示 |

**时序控制条从左到右**：

1. **运行 / 暂停**：开始或冻结虚拟时间。运行中按钮变绿并显示「暂停」；
2. **单步**：手动推进一个逻辑拍（虚拟时间 **+10 ms**），暂停态也可用，用来一拍一拍地看触发器/计数器；
3. **复位时间**：虚拟时间归零并重新求值（**不清导线、不清芯片**）；
4. **速度** 1x / 10x / 100x：虚拟时间倍率。1x 时 1 秒真实时间 = 1 秒虚拟时间；
5. **时钟使能**：勾选 = 时钟输出区有信号；取消 = 时钟插孔呈高阻（`Z`）；
6. **虚拟时间读数**：形如 `2.68 s`。

**工具栏从左到右**：

1. **导线颜色**：7 个色块（红 / 黑 / 蓝 / 黄 / 绿 / 橙 / 紫），点击选中当前接线颜色；
2. **撤销**：撤销最近一次接线操作（快捷键 `Ctrl+Z`）；
3. **重做**：重做上一次被撤销的操作（快捷键 `Ctrl+Y` 或 `Ctrl+Shift+Z`）；
4. **清空导线**：一次删除全部导线（可撤销）；
5. **导出**：下载 `.dlab.json` 工程文件；
6. **导入**：选择 `.dlab.json` 文件还原工程；
7. **显示导线**：切换「透视面板」，临时隐藏全部飞线以看清面板；
8. **状态区**：显示当前选中插孔、导线数量、最近操作与短路告警。

## 2. 基础操作

### 2.1 接一根线

1. 点击面板上任意一个**插孔**（金色圆孔）→ 该孔高亮，状态栏提示已选中；
2. 移动鼠标 → 出现一条跟随鼠标的预览曲线；
3. 点击**另一个插孔** → 生成一根自然下垂的贝塞尔飞线，两端插孔短暂高亮。

> 若两个孔已经在同一个连通网里，或它们之间已有导线，会拒绝连接并给出中文提示。

### 2.2 取消接线

- 再次点击**同一个插孔**，或按 `Esc`。

### 2.3 删除一根线

- **右键点击**该导线；或
- **左键点击**导线选中后按 `Delete`。

### 2.4 换颜色

1. 先在工具栏点选一个颜色，之后新接的线就用该颜色；
2. 或右键已有导线，在菜单中选择颜色。

### 2.5 悬停高亮

- 悬停**插孔**：插孔放大并描边高亮；
- 悬停**导线**：导线加粗，**两端插孔同时高亮**，便于确认这根线接在哪里。

## 3. 验收实验一：开关控制发光二极管（最小闭环）

**目标**：拨动逻辑电平开关 5K1，点亮发光二极管显示区的 4L1。

### 接线步骤

1. 找到**逻辑电平输出**区（面板左下偏下，标着「逻辑电平输出」的一排 16 个开关）；
2. 找到 5K1 上方的输出插孔，标注 **5K1**（在 5L1 指示灯下方）；
3. 找到**发光二极管显示**区（面板左上方，标着「发光二极管显示」）；
4. 找到标注 **4P1** 的输入插孔；
5. 点击 **5K1 插孔** → 点击 **4P1 插孔**，完成接线（建议用红色线）。

### 观察

- 面板上 5K1 对应的**自锁按键开关**（在「逻辑电平输出」区下方）——点击它拨到高电平；
- **4L1 指示灯应当点亮**（变成红色发光）；
- 再点一次开关拨回低电平 → **4L1 熄灭**。

> 这一步同时验证了三件事：接线生效、电气连通、面板视觉联动。

## 4. 验收实验二：与非门（74LS00）真值表

**目标**：在 A 数电开发模块的 UA 插座上插入 74LS00，用开关作为输入，验证四组与非门。

### 接线步骤

1. 找到**A 数电开发模块**（面板中部左侧，黑色底板，标着大写 A）；
2. UA 区（14 脚插座，位于该模块左侧）——点击插座可插入芯片，选择 **74LS00**；
3. 74LS00 引脚定义：`1A=1, 1B=2, 1Y=3`，`VCC=14, GND=7`；
4. 接线：

| 起点 | 终点 | 说明 |
| :-- | :-- | :-- |
| `pwr:5V1`（电源区 +5V） | `devA:VCC` | 芯片供电（A 模块左侧 VCC 孔） |
| `gnd:GND1`（接地区 GND） | `devA:GND` | 芯片接地（A 模块右侧 GND 孔） |
| `sw:5K1` | `devA:A1` | 开关 5K1 → 第 1 脚（1A） |
| `sw:5K2` | `devA:A2` | 开关 5K2 → 第 2 脚（1B） |
| `devA:A3` | `led:4P1` | 第 3 脚（1Y）→ 指示灯 4L1 |

### 观察

依次拨动 5K1 / 5K2，4L1 应满足**与非**真值表：

| 5K1 (1A) | 5K2 (1B) | 4L1 (1Y) |
| :--: | :--: | :--: |
| 0 | 0 | **1（亮）** |
| 0 | 1 | **1（亮）** |
| 1 | 0 | **1（亮）** |
| 1 | 1 | **0（灭）** |

> 只有两个输入都为高时输出才为低——这正是「与非」的含义。

## 5. 验收实验三：短路保护告警

**目标**：验证 VCC 与 GND 被直接短接时的保护机制。

### 接线步骤

1. 用一根导线直接连接 **电源区的 +5V**（`pwr:5V1`）与 **接地区的 GND**（`gnd:GND1`）。

### 观察

- 底部状态栏立即出现**红色告警**，提示短路；
- 该连通网被判为 `X`（冲突态），相关导线渲染为故障色；
- 删除这根导线后，告警自动消失。

> 现实中这样接会烧电源，仿真里提前拦住——这是「逻辑审查」的第一道防线。

## 6. 验收实验四：导入导出

### 导出

1. 接好若干导线、拨好几个开关；
2. 点击工具栏 **导出** → 浏览器下载 `dlab-YYYYMMDD-HHmm.dlab.json`。

文件内容形如：

```json
{
  "format": "dlab-project",
  "version": 1,
  "savedAt": "2026-10-28T14:00:00.000Z",
  "power": true,
  "switches": { "5K1": 1, "5K2": 0 },
  "chips": { "devA:UA": "74LS00" },
  "wires": [
    { "id": "w1", "from": "sw:5K1", "to": "devA:A1", "color": "#ef4444" }
  ]
}
```

### 导入

1. **刷新页面**（导线应当全部消失）；
2. 点击工具栏 **导入** → 选择刚才下载的文件；
3. 导线、开关状态、已插芯片**完全还原**。

> 导入时会校验 `format` / `version` / 插孔 ID 是否存在；文件不合法时给出中文报错，
> 并且**不会破坏当前已经画好的工程**。

## 9. 常见问题

**Q：双击 index.html 后是白屏？**
A：页面会自动显示「应用无法启动」并列出缺失的模块名。按提示检查 `src/` 下对应文件是否存在。

**Q：点了插孔没有反应？**
A：确认点在**金色插孔**上而不是旁边的丝印文字；插孔悬停时会放大并高亮。

**Q：飞线挡住面板看不清？**
A：点工具栏 **显示导线** 切换为透视模式。

**Q：数码管为什么只有 8 只、而且 3~8 号只有 5 个引脚？**
A：这是**实物面板的真实情况**——原实验箱面板上 1/2 号数码管引出了完整 8 段（a~g + dp），
3~8 号只引出了 a/b/c/d/dp 五段。本项目严格照实物还原，没有臆造。

**Q：为什么 5K1 拨高后 4L1 没亮？**
A：检查导线是否接在 **4P1**（发光二极管显示区的输入孔）而不是别的孔；
再检查导线是否真的接上（右键可删除，说明选中了）。

**Q：点了 DIP 插座没反应？**
A：确认点在**插座本体**（黑色长条）上，不是旁边的金孔或丝印。悬停时会出现蓝色描边。
菜单弹出后点型号即插上；再点插座可拔下。

**Q：插上芯片但电路不工作？**
A：先确认 VCC（14 或 16 脚）与 GND（7 或 8 脚）接到了 `devA:VCC` / `devA:GND`。
芯片没供电时所有输出都是高阻，看起来就像"没反应"。

**Q：计数器/触发器不动？**
A：检查时序控制条是否处于**暂停**状态（按钮显示「运行」即为暂停）。
另外确认时钟插孔（`clock:1HZ` 等）真的接到了芯片的时钟脚。

**Q：为什么面板上没有 NE555？**
A：本实验箱只有 14P / 16P / 20P 三种 DIP 插座，**没有 8 脚插座**，NE555 物理上插不进去。
本项目严格照实物还原，没有臆造一个不存在的插座。

## 10. 时序实验怎么做

时序芯片（74LS74 / 112 / 160 / 161 / 194 / 273）需要时钟才能工作。步骤如下：

### 10.1 用板载时钟

1. 在插座上插好芯片（例如 `devA:UA` 插 74LS74）；
2. 用导线把 `clock:1HZ` 接到芯片的时钟脚（74LS74 的 `1CLK` = 第 3 脚 = `devA:A3`）；
3. 用导线把 `devA:VCC` 接到 `devA:A14`（VCC）、`devA:GND` 接到 `devA:A7`（GND）；
4. `~1CLR`（第 1 脚 = `devA:A1`）与 `~1PRE`（第 4 脚 = `devA:A4`）接 VCC；
5. 输出 `1Q`（第 5 脚 = `devA:A5`）接 `led:4P1`。

### 10.2 观察

- 时序控制条默认就在**运行**（真实实验箱上电后时钟就在走）；
- 1Hz 时钟下，4L1 每 1 秒翻转一次；
- 点 **暂停** → 时钟冻结，4L1 停在当前状态；
- 点 **单步** → 每次虚拟时间 +10 ms，可以一拍一拍地看它什么时候翻转；
- 点 **100x** → 高速时钟（1KHZ 以上）也能看清翻转过程。

> 单脉冲按键 6K1~6K6 的脉冲宽度是 **200 ms 虚拟时间**。暂停状态下按 6K1，
> 脉冲会"卡住"不结束——因为虚拟时间不再前进。这是符合预期的：
> 暂停的含义就是"时间停止"。
