> 实验平台模块化结构，标配6个模块、1个嵌入式处理器与数据采集卡、1个11.6寸人机交互液晶屏

公共显示模块：

> 16位逻辑电平显示LED，高低电平三套分别用三种颜色显示发光管区分；2位共阴极数码管显示电路

模块清单还包括：

> 8位逻辑分析仪；2路逻辑笔；1路模拟信号源
> 2路三态逻辑笔测量电路；8路逻辑分析仪；低频信号源

集中测试模块：

> 4路时钟信号输出接口，在液晶上可设置产生1Hz、2Hz、4Hz、8Hz、1KHZ、10kHz、1MHz等多种
> 时钟信号，时钟源支持脉冲1Hz-1MHz可调

标配 6 个模块：集中测试模块、公共显示模块、数电开发模块（2块）、阻容与AD/DA模块、自主设计模块。

注意：RZ9658G 是**数智化**版本（11.6 寸屏），与 RZ9658（早期 8 寸液晶）规格并不完全相同；

## 4. 本项目对齐决策（由此前网络调研 + 面板丝印得出）

官网无详细数值，故本项目采用如下**可辩护**模型（实现见 `src/core/engine.js` §6.1）：

| 项 | 模型值 | 依据 |
| :-- | :-- | :-- |
| 信号源 DDS 频率 | 1Hz ~ 1MHz，1-2-5 十进步进 | RZ9658G 页「时钟源支持脉冲1Hz-1MHz可调」+ 常规 DDS 面板习惯 |
| DDS 幅度 | 0 ~ 5V，0.5V 步进；低于 TTL 阈值 2.5V 输出恒为低 | 数字实验箱 TTL 电平体系；面板丝印无幅度刻度 |
| DDS 波形 | 方波（50% 占空比）/ 脉冲（占空比 10%，脉宽钳 0.05~500ms） | 面板三只指示灯：频率 / 幅度 / **脉冲** |
| 逻辑笔 | TTL 模式悬空判高；CMOS 模式悬空判高阻 | SW1 拨动开关 + 丝印「COMS / TTL」（面板原文即拼作 COMS） |
| 电位器 | 5V 满量程线性分压，滑动端 ≥2.5V 判高 | 1/2/3 三孔 + 旋钮外观 |
| 蜂鸣器 | 有源型，自振 2.7kHz，高电平即鸣 | 有源蜂鸣器是数字实验箱标配 |
| 编码器 2SS1 | 点击切换调节参数（频率→幅度→波形），旋转一格增减 | 面板三只参数指示灯 + 旋转编码器外观 |

历史调研结论（此前会话联网确认）：RZ9658 内置 8 寸彩色液晶，标配 8 路逻辑分析仪、
1 路示波器、1 路 DDS 信号源（示波器 ACH1 与 DDS 为内置仪器，面板只留接线孔与控制钮），
两片 EP4CE6 FPGA 共 160 IO。该结论与官网现存公开页面一致但无独立页面可引，保留于此备忘。
